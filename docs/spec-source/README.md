# Specification source

The primary requirements source is the 50-page PDF *NHI-Blast: Complete
Architecture and Build Specification (v2.0)*, supplied with the project brief.
The PDF itself is not distributed in this repository. Its extracted, lightly
normalised text is committed as `docs/SPEC.md`, which is the normative source for
this repository; the extraction method and completeness note are at the top of
that file.

The superseded 20 October 2026 flagship blueprint is **not** committed: it is
historical context only, it contradicts v2.0 on several researched claims, and
specification section 1 supersedes it explicitly.
