## Corrections applied while building M1

| Defect | Root cause | Resolution |
| --- | --- | --- |
| `UnboundLocalError` for every non-`workflow_call` subject build | Audience loop was missing; the name existed only in a different branch | Explicit audience loop; candidate assembly split into helpers |
| Solver crashed on multiple matched candidates | `SubjectCandidate` includes a dict and is unhashable, so set deduplication raised | Deduplicate on `(subject, format, trigger, audience)` |

## Corrections applied during the 0.2.0 report redesign

| Defect | Root cause | Resolution |
| --- | --- | --- |
| Printed/PDF graph was blank or partially rendered | The browser layout engine rendered into a canvas that the print path did not reproduce, and the graph page had no deterministic print geometry | Compute the layered layout in Python, emit accessible inline SVG, and print the same SVG on an A3 landscape page; `tests/test_graph_layout.py` pins determinism, stage order and non-overlap, and a fresh PDF was inspected |
| Long graph labels were clipped or overlapped | Fixed node widths with no measurement of the rendered text | Measure label width with a bounded wrapping routine, size each node from its content, and keep the full label in the accessibility metadata |
| Evidence confidence was hard to read in the graph | All edges shared one stroke treatment | Encode confidence in stroke style (solid, dashed, dotted) and verify the CSS classes in tests |
| Graph interaction was mouse-only | Nodes were plain SVG groups | Make nodes roving-tab-stop buttons with spatial arrow navigation, Enter selection and Escape clear, and verify the interaction pass |
| Boot-failure message was invisible | The boot class was removed before the failed state was shown, so the status element stayed hidden behind the body-hiding rule | Add `html.boot-failed` body and status rules; a corrupted-data browser test asserts the message and the hidden body; regression assertions pin it |
| Hidden navigation link still rendered | The `.toc a` flex rule overrode the user-agent `[hidden]` rule | Add `.toc a[hidden] { display: none; }` and assert zero shown hidden links in the browser audit |
| Active navigation was one section behind | An IntersectionObserver treated short sections as never current | Replace it with a scroll-position calculation plus the bottom-of-page rule, and verify every link in all eight contexts |
| Printed survival tables collided | Fixed table layout and `nowrap` cells squeezed the evidence column | Use print-only auto layout, allow wrapping, keep header groups, and repeat the A3 graph page; the regenerated PDFs have no collisions |
| Multi-scenario lead finding could come from another scenario | The lead was chosen from the report-wide findings list | Scope the lead to the selected scenario with a report-wide fallback, and state `all entrypoints` in the summary note when several scenarios exist |
| Report shipped three vendored layout scripts | The earlier renderer required Cytoscape, dagre and cytoscape-dagre at runtime | Remove the vendor assets and manifest entries, reduce the document to two hashed inline scripts, and document the specification change; the artifact checker and tests now require the reduced asset set. | Report needed a premium motion layer without weakening the CSP | The offline report had no animation library, and a CDN or remote load would violate the offline and CSP contract | Vendor the official Motion 14.7.1 UMD build under `report/assets/vendor`, pin its SHA-256 and MIT licence in `MANIFEST.json`, embed it as a third hash-covered inline script, and restrict its use to presentation with complete reduced-motion and print fallbacks; tests reject an unpinned runtime, a non-Motion build, a missing MIT licence or a closing script tag |
