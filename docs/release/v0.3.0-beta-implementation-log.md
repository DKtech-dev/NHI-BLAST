and loads; the rank report keeps its own label `nhi-blast-report/1.0/rank` because rank output is unchanged.

### Execution session 2026-11-02 (plan revision 2)

Work was split between the lead and three teammates with disjoint write scopes; the lead reviewed
every golden change against its cause before accepting it.

- **Step 0.** The working tree was a partial revert of A1 and did not import. A patch of it was
  saved, the tracked files were restored from HEAD, and the baseline ran clean (821 passed, ruff
  and mypy clean).
- **A1'/A2'/A3.** `core/canonical.py`, `core/context.py`, `core/completeness.py`; the engine
  fingerprint registry `tests/golden/engine-fingerprint.json`.
- **D1'.** Condition evaluator rewrite with a 276-vector oracle and a Hypothesis soundness property
  (an Unknown-to-Absent mutant is killed). Changed existing tests are listed in the teammate
  report: `test_policy_eval` (a conditional Deny no longer leaves a definite Allow),
  `test_conditions` and `test_properties` (empty value sets).
- **D2'/D3'.** Session provenance, configure-aws-credentials inputs, `[github]` configuration.
- **B.** Diff and baseline. A real-CLI check found that re-attribution of a trust finding between
  scenarios produced "resolved" plus "new" for a finding that still existed; scenario was removed
  from the key for non-scenario rules and the repro became a regression test.
- **C.** What-if and playbook; the replay guard replays on the saved graph minus synthetic
  scenario nodes.
- **G0/G4/A3-HTML.** Theme and switcher; completeness panel. Browser suite: 31 tests per engine.
- **Defects found and fixed on the way.** (1) `Config.path` was an absolute host path in evidence
  and edge ids; (2) a read-then-write of a file larger than the read tool's output cap truncated
  `graph/builder.py` once and was restored from git and re-applied with an in-place script;
  (3) the first engine fingerprint registration had embedded the host path from (1) and was
  re-registered (the entry was never released).
